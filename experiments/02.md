RoBERTa-Based Depression Classification

Objective

The objective of this component was to explore whether contextual text representations could improve depression classification compared with traditional text-based features.

Work Completed

* Used a pretrained RoBERTa model to extract contextual embeddings from social-media text.
* Applied mean pooling to obtain a 768-dimensional representation for each text.
* Used Logistic Regression to classify the embeddings into three classes: severe, moderate, and not depression.
* Evaluated the model using accuracy, Macro-F1, Weighted-F1, balanced accuracy, and class-specific performance.

Current Results

Metric	Score
Accuracy	0.620
Macro-F1	0.550
Weighted-F1	0.605
Balanced Accuracy	0.525
Severe-class Recall	0.30

The results suggest that contextual embeddings improved overall performance compared with the TF-IDF baseline. However, the model still struggles to identify severe cases reliably.

Limitations

* The experiment uses extracted embeddings rather than task-specific fine-tuning.
* Mean pooling may not preserve all relevant information in a text.
* The severe class remains difficult to identify.
* The results need to be analysed further using a confusion matrix and per-class metrics.

Next Steps
