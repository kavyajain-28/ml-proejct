Dataset Preparation and Baseline Classification

1. Objective

The objective of this component was to prepare a reliable dataset for depression classification and establish a baseline model against which more advanced approaches could be evaluated.

The project focuses on three classes: severe, moderate, and not depression.

An important challenge identified during this stage was the imbalance between classes, along with the possibility that examples from different classes may contain similar language.

2. Dataset Preparation

Work Completed

* Loaded and inspected the available training, development, and test datasets.
* Examined class distributions to understand the extent of class imbalance.
* Checked for duplicate text entries and instances where identical text was associated with conflicting labels.
* Investigated overlaps between the dataset splits to identify potential data leakage.
* Separated conflicting entries for further inspection and created a cleaned dataset.
* Checked for missing values and prepared the cleaned text-label data for modelling.
* Established a consistent dataset for subsequent experiments.

Data Quality Findings

The initial inspection revealed substantial duplication and some instances in which the same text was associated with different labels.

These issues were important because duplicate examples can distort evaluation, while conflicting labels introduce ambiguity into the learning process.

The cleaning process was therefore intended to improve dataset reliability before comparing classification approaches.

Class Imbalance

After cleaning, the class distribution was:

Class	Number of samples
Moderate	3,510
Not depression	2,645
Severe	706
Total	6,861

The severe class was considerably smaller than the moderate class. The majority-to-minority ratio was approximately 4.97:1.

This imbalance established an important challenge for subsequent modelling: a classifier could achieve reasonable overall accuracy while still performing poorly on severe cases.

3. Baseline Model

Objective

The baseline was developed to establish a reference point for evaluating more advanced models.

TF-IDF with Logistic Regression was selected as a conventional text-classification approach. It provides a relatively simple and interpretable starting point before introducing contextual embeddings or additional linguistic features.

Methodology

1. Converted text into numerical representations using TF-IDF.
2. Used the resulting feature vectors as input to Logistic Regression.
3. Trained the classifier to predict one of the three depression-related classes.
4. Evaluated its performance using multiple metrics, including metrics that account for class imbalance.

Recorded Results

Metric	Score
Accuracy	0.466
Macro-F1	0.430
Weighted-F1	0.479
Balanced Accuracy	0.475

These results indicate that the baseline has limited classification performance. In particular, the Macro-F1 and balanced accuracy scores suggest that performance across the classes needs improvement.

The baseline is still valuable: it provides a reference against which the RoBERTa and psycholinguistic approaches can be assessed.

4. Limitations Identified

Dataset Limitations

* The class distribution is imbalanced, particularly for the severe class.
* Duplicate texts and conflicting labels create potential sources of noise.
* Similar language across classes may make some examples difficult to distinguish.
* The effects of cleaning decisions on the final dataset should be documented carefully.

Baseline Limitations

* TF-IDF primarily represents text through weighted word and phrase frequencies.
* It does not directly capture contextual meaning in the way contextual language models can.
* Similar words can occur in texts with different meanings or emotional contexts.
* The imbalance between classes may contribute to weaker minority-class performance.

5. Next Steps

1. Validate the data splits: Confirm that the final training, development, and test sets are appropriately separated and that evaluation is not affected by duplicate leakage.
2. Analyse class-wise performance: Inspect the confusion matrix and precision, recall, and F1 scores for each class.
3. Investigate class imbalance: Determine which classes are most affected and evaluate suitable imbalance-handling strategies.
4. Investigate class overlap: Examine whether examples from different classes share similar textual characteristics.
5. Maintain a consistent evaluation protocol: Use comparable splits and metrics when assessing the baseline, RoBERTa, and psycholinguistic approaches.
6. Preserve the baseline: Keep the TF-IDF model as a reference rather than replacing it with a more complex model without comparison.

6. Contribution to the Overall Project

This component established the dataset and experimental foundation for the larger project.

The data-cleaning stage addressed duplication, conflicting labels, and class distribution. The baseline then provided an initial measurement of how well a conventional text-classification model could distinguish the three classes.

The results motivate the investigation of more expressive representations and additional linguistic features. They also establish class imbalance and potential class overlap as challenges to investigate further.

The dataset and baseline therefore serve as the common foundation for the independently developed RoBERTa and psycholinguistic components.
